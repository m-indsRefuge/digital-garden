# Digital Garden V0-B.2 — QPainter Visual Refinement Design

**Status:** Approved direction; written refinement spec for user review  
**Date:** 2026-08-15  
**Branch:** `build/digital-garden-v0b2-byte-continuation`  
**Renderer:** PySide6 / QWidget / QPainter  
**Baseline:** 97 tests green after static weather atmosphere

## 1. Purpose

This refinement keeps the current procedural QPainter renderer and improves it as far as is sensible within the existing technology stack. The target is a polished, coherent, stylised miniature desktop garden generated by one visual system — not painterly concept-art fidelity and not a collage of separately authored/generated raster assets.

The Garden World remains authoritative. Rendering improvements may only change how existing `GardenRenderState` values are presented.

## 2. Visual target

The V0-B.2 QPainter generation should feel:

- organic rather than geometric;
- dimensional rather than flat;
- visually coherent across bonsai, ground, vines, weather and HUD;
- calm and desktop-appropriate;
- recognisably the same seeded garden as state changes;
- richer through deterministic procedural detail rather than image swapping.

The current painterly concept remains a long-term art-direction reference, not the V0-B.2 acceptance threshold.

## 3. Rendering strategy

The renderer will move from mostly direct object drawing toward a small multi-pass illustration pipeline while retaining QWidget/QPainter.

Conceptual order:

```text
structural shadow / depth pass
    ↓
ground material pass
    ↓
ground botanical detail
    ↓
bonsai structural pass
    ↓
foliage shadow mass
    ↓
main foliage mass
    ↓
highlight / rim-detail pass
    ↓
vines
    ↓
weather / atmosphere
    ↓
integrated HUD and collapse affordance
```

Intermediate offscreen `QImage` rendering may be introduced only where it provides a clear visual benefit such as soft shading, texture, or controlled compositing. Supersampling may be evaluated later if the direct renderer remains visibly aliased at production size.

## 4. Bonsai refinement

The bonsai remains procedural and seed-stable.

Improve it through:

- more irregular, asymmetrical canopy silhouettes;
- layered foliage tones instead of a single flat mass;
- interior foliage shadow clusters;
- limited highlight/rim clusters tied to one coherent light direction;
- stronger branch taper and branch hierarchy where existing scene structure permits;
- richer trunk treatment using deterministic highlight/shadow marks rather than raster bark assets;
- clearer root contact and grounding shadow;
- state-sensitive stress/growth/density cues without replacing the tree identity.

The refinement must not introduce per-frame randomness.

## 5. Ground refinement

The ground patch should gain visible depth and material character while preserving the existing organic outline and geometry-derived mask.

Improve it through:

- a subtle underside/contact-depth treatment;
- coherent directional shading across the ground surface;
- deterministic soil/moss mottling;
- richer moss tonal breakup;
- better small-scale clover, grass, flower and stone layering;
- moisture-dependent darkening and wet highlights;
- restrained edge breakup that remains deterministic and mask-safe.

The ground must still read as one continuous living patch rather than a pile of unrelated decorative objects.

## 6. Lighting and atmosphere

Use one consistent implied light direction for the entire scene. Lighting remains illustrative rather than physically based.

Authoritative weather controls static mood:

- `SUNNY`: warmer/brighter highlights and clearer contrast;
- `CLOUDY`: softer, cooler, lower-contrast treatment;
- `RAINY`: darker/cooler material treatment and stronger wet highlights.

No temperature, wind, or other unsupported environmental facts may be invented.

Animation remains outside this refinement campaign unless already required by the broader V0-B design.

## 7. Vine and anchor refinement

Keep the anchor and edge vines generated by the same scene language.

Improve them through:

- variable stem emphasis within existing geometry;
- layered leaf values rather than flat identical leaves;
- subtle highlight/shadow treatment;
- stronger visual continuity between patch vines and compact anchor;
- existing `anchor_state` vitality mapping preserved.

Window interaction masks must continue to be derived from the same prepared render geometry.

## 8. HUD and controls

The HUD should stop reading as a conventional green application panel while remaining crisp and legible.

Refine it toward:

- softer translucent backing;
- reduced rectangular dominance;
- botanical visual integration without sacrificing text readability;
- clearer information hierarchy for `CONDITION` and `WEATHER`;
- a collapse affordance that visually belongs to the garden instead of looking like a stock widget.

The text itself remains real Qt text. No decorative UI element may imply unsupported Garden state.

## 9. Implementation sequence

Work proceeds in small TDD slices, each locally verified before the next:

1. depth foundation — grounding/contact shadows and directional light convention;
2. ground material refinement;
3. bonsai foliage/trunk depth refinement;
4. vine/anchor value refinement;
5. HUD/collapse visual integration;
6. static weather polish across the whole composition;
7. optional supersampling/performance experiment only if visual evidence justifies it;
8. Windows manual visual acceptance and final regression gate.

Each slice must preserve the existing presentation boundary and deterministic scene identity.

## 10. Testing and acceptance

Automated gates remain:

- focused renderer tests for each new visual behavior;
- full pytest suite;
- Ruff lint;
- Ruff format;
- `git diff --check`;
- canonical V0-A 240-tick output unchanged.

Visual behavior should be tested at the lowest stable level possible: prepared scene models, deterministic geometry, or meaningful rendered-pixel/region assertions. Tests must avoid asserting arbitrary artistic constants where a semantic behavior can be asserted instead.

Manual Windows acceptance will judge:

- whether the garden feels materially deeper and less flat;
- whether the bonsai reads as richer without becoming noisy;
- whether the ground and tree belong to one lighting environment;
- whether the compact anchor and expanded patch remain coherent;
- whether the HUD feels integrated rather than bolted on;
- whether weather moods are visible but calm;
- whether performance and interaction remain acceptable.

## 11. Explicit non-goals

This campaign does not introduce:

- raster asset collage or generated art packs;
- photorealistic or painterly concept-art reproduction;
- a new graphics engine;
- Qt Quick/QML migration;
- OpenGL/RHI/shader infrastructure;
- new Garden World physics or environmental state;
- B.3 interaction actions;
- B.4 animation campaign;
- neural, LLM, or learned rendering behavior.

A future high-fidelity renderer may revisit those choices if capability and evidence justify it.
